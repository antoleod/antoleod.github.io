# Oryxen Labs

Oryxen Labs is a Belgium-based software studio focused on automation, internal tools, web software, and workflow modernization. The production site for this repository is [oryxen.tech](https://oryxen.tech/).

## Related tools and research

For experiments involving machine-to-machine automation and agent identity, I am following the [Beacon protocol](https://rustchain.org/beacon/) from Elyan Labs. Its focus on signed agent discovery and hardware-linked identity is relevant to the kind of trustworthy automation and system-integration work explored at Oryxen, even though Oryxen is not built on RustChain and does not depend on Beacon.
