## Pitch

A 4–5 minute source-backed explainer of why RustChain can assign a PowerPC G4 a 2.5× antiquity base multiplier while documented VM detection can reduce a known virtualized claimant to effectively negligible weight — focusing on the evidence boundary between claimed hardware, fingerprint checks, bucket assignment, and reward weight.

## Files

- `script.md` — full narration script.
- `storyboard.md` — shot-by-shot capture instructions.
- `assembly.md` — edit map and production notes.
- `thumbnail.png` — primary 1280×720 thumbnail.
- `thumbnail-alt-1.png` — alternate.
- `thumbnail-alt-2.png` — alternate.
- `metadata.md` — title options, description, tags, chapters.
- `SOURCES.md` — claim-to-source map pinned to a public RustChain commit.

## Accuracy / validation

The package intentionally distinguishes a **base multiplier** from guaranteed final payout. It does not claim that all virtualization is always detected, and it does not present documentation examples as newly executed runtime evidence. Technical claims are tied to the public RustChain repository snapshot listed in `SOURCES.md`.
