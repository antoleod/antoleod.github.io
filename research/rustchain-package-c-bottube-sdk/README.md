# BoTTube SDK — Type C Shorts package

Publication-ready YouTube Shorts / clip kit for RustChain bounty #16601, Type C.

**Angle:** an AI agent does not need browser automation to interact with BoTTube: the public SDK exposes read operations, while authenticated SDK/API calls cover write operations such as upload, comment, vote, tip, and delete.

This package deliberately avoids claiming that a live upload was performed. The visual plan gives the publisher exact capture instructions using the official CLI uploader example, with secrets kept off-screen.

## Files

- `script.md` — <=60-second narration
- `capture-instructions.md` — exact 9:16 shot plan
- `metadata.md` — title, description, tags and thumbnail text
- `SOURCES.md` — source map for every factual claim
